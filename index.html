// About the Project

A smarter approach to minimart security

Traditional CCTV systems rely heavily on continuous human monitoring — difficult for small businesses like EC Minimart with limited personnel. ISMDAS-ECM introduces an intelligent, camera-based detection system that assists store security instead of replacing it.

Developed as an undergraduate thesis at Ramon Magsaysay Memorial Colleges – Marbel Inc., the system combines affordable hardware with practical software to deliver a reliable monitoring and alert solution.

  • Real-time suspicious motion detection
  • Automated alerts to authorized personnel
  • Centralized incident logging and review
  • Accessible web-based monitoring dashboard
  • Low-cost ESP32-CAM based deployment
